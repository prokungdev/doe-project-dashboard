# DOE Project Dashboard (กรมการจัดหางาน)
### Dashboard จัดสรรเป้าหมายการดำเนินงาน ประจำปีงบประมาณ พ.ศ. 2570

ระบบแดชบอร์ดรายงานและติดตามการจัดสรรเป้าหมายการดำเนินงานของกรมการจัดหางาน ประจำปีงบประมาณ พ.ศ. 2570 ในรูปแบบ **Single-Page Application (SPA)** แบบ Standalone เปิดใช้งานได้ทั้งแบบ Offline บนเครื่อง หรือดูออนไลน์ผ่าน GitHub Pages ได้ทันที

🌐 **เข้าชมออนไลน์ (Live Demo):** [https://prokungdev.github.io/doe-project-dashboard/](https://prokungdev.github.io/doe-project-dashboard/)

---

## 📌 จุดเด่นและฟังก์ชันการใช้งาน (Key Features)

### 1. 📊 ภาพรวมทั้งกรม (Executive Overview)
- สรุปเป้าหมายการดำเนินงานรวมทั้งกรม **11,367,538** เป้าหมาย
- ครอบคลุม **124 หน่วยงาน** และ **11 โครงการสำคัญ**
- แสดงสัดส่วนโครงการหลัก และกราฟแท่งเปรียบเทียบเป้าหมายจำแนกตามไตรมาส Q1–Q4

### 2. 🎯 จัดสรรเป้าหมายรายโครงการ (Project Allocation View)
- สามารถเลือกดูแต่ละโครงการได้ว่า**จัดสรรเป้าหมายให้กับจังหวัดหรือหน่วยงานใดบ้าง**
- **ฟิลเตอร์ด่วน:**
  - `📍 เฉพาะจังหวัด (76 จังหวัด)`: คัดกรองดูเฉพาะสำนักงานจัดหางานจังหวัดทั่วประเทศ
  - `ส่วนกลาง`: หน่วยงานภายในส่วนกลาง 26 หน่วยงาน
  - `ศูนย์ภาค`: ศูนย์บริการจัดหางาน 5 ศูนย์
  - `ด่าน`: ด่านตรวจคนหางาน 17 ด่าน
- **สลับมุมมองตารางได้ 2 รูปแบบ:**
  - **ตารางรายไตรมาส:** เป้าหมายรวม และแจกแจง Q1–Q4
  - **ตารางรายเดือน (12 เดือน):** แจกแจงละเอียดครบทั้ง 12 เดือน (ต.ค. 69 – ก.ย. 70) ของทุกจังหวัด
- **ระบบค้นหาแบบ Real-time:** ค้นหาตามชื่อจังหวัดหรือชื่อหน่วยงานได้ทันที
- **ปุ่มเปิดดูรายละเอียด:** คลิกเพื่อเจาะลึกไปยังหน้ารายละเอียดของหน่วยงานนั้นๆ ได้ทันที

### 3. 🏢 เจาะลึกรายหน่วยงาน / จังหวัด (Unit Drill-down)
- แสดงเป้าหมายรวม กราฟแท่งรายไตรมาส และ Sparkline แนวโน้มการดำเนินงาน
- สลับดูได้ทั้ง **"ตารางรายโครงการ"** และ **"ตารางรายเดือน 12 เดือน"** พร้อมผลรวมท้ายตาราง

### 4. ↔️ เมนูด้านซ้ายปรับขนาดได้อิสระ (Resizable & Collapsible Sidebar)
- **ลากปรับความกว้างได้:** คลิกลากที่ขอบขวาของ Sidebar เพื่อขยายหรือลดความกว้างเมนูได้ตามต้องการ (180px – 520px) พร้อมจำขนาดไว้ใน LocalStorage
- **ย่อเมนู (Mini Mode):** มีปุ่มกดย่อเมนูแบบกะทัดรัด พร้อม Tooltip แสดงชื่อเมนู

### 5. ⚡ Zero-Server / Standalone Architecture
- รวมข้อมูล JSON และ UI ไว้ในไฟล์ HTML เดียว (`index.html`)
- ไม่ต้องติดตั้ง Database หรือรัน Backend Server
- โหลดเร็ว ตอบสนองทันที ปลอดภัย และนำไปใช้งานได้ฟรี 100%

## 🗂️ โครงสร้างข้อมูล (Data Structure)

| กลุ่มหน่วยงาน | จำนวนหน่วยงาน | คำอธิบาย |
| :--- | :---: | :--- |
| **สำนักงานจัดหางานจังหวัด** | 76 | สำนักงานจัดหางานจังหวัดทั่วประเทศ |
| **หน่วยงานส่วนกลาง** | 26 | สำนัก / กอง ต่างๆ ภายในกรมการจัดหางาน |
| **ด่านตรวจคนหางาน** | 17 | ด่านตรวจคนหางานตามจุดผ่านแดน |
| **ศูนย์บริการจัดหางาน** | 5 | ศูนย์บริการจัดหางานประจำภาค |
| **รวมทั้งหมด** | **124** | **หน่วยงาน** |

**โครงการหลัก 11 โครงการ:**
1. โครงการบริหารจัดการแรงงานต่างด้าว
2. โครงการป้องกันปัญหาการค้ามนุษย์ด้านแรงงาน
3. โครงการศูนย์ประสานแรงงานประมง
4. โครงการสร้างภูมิคุ้มกันให้แรงงานห่างไกลยาเสพติด
5. โครงการจัดหางานและส่งเสริมการประกอบอาชีพให้ผู้ผ่านการบำบัด
6. โครงการศูนย์อำนวยความสะดวกด้านการจ้างแรงงานต่างด้าว
7. โครงการเตรียมความพร้อมแก่กลุ่มเป้าหมายก่อนเข้าสู่ตลาดแรงงาน
8. โครงการบริการจัดหางานและอาชีพ
9. โครงการสร้างงาน สร้างอาชีพ ให้กลุ่มเปราะบาง
10. โครงการออกใบอนุญาตทำงานตามกฎหมายว่าด้วยการส่งเสริมการลงทุน
11. โครงการพัฒนาระบบและการบริหารจัดการภาครัฐ

## 🚀 วิธีการใช้งานและการ Build

### การเปิดใช้งานแบบ Local:
- ดับเบิลคลิกไฟล์ `index.html` หรือ `dashboard.html` เพื่อเปิดใช้งานบนเบราว์เซอร์ได้ทันที โดยไม่ต้องใช้อินเทอร์เน็ต

### การ Rebuild Dashboard เมื่อมีการอัปเดตข้อมูล:
หากมีการแก้ไขข้อมูลใน `dashboard_data.json` สามารถสั่ง Compile แดชบอร์ดใหม่ได้ด้วยคำสั่ง:

```bash
python build_dashboard.py
```

ระบบจะสร้างไฟล์ `index.html` และ `dashboard.html` ที่มีข้อมูลเวอร์ชันล่าสุดให้ทันที
